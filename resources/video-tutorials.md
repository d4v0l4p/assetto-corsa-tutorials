## Converting cars from other games

| Topic | Link |
|-------|------|
| CSR2 car conversion | [Playlist by ZD](https://www.youtube.com/playlist?list=PLjKj7c74gph7xjtkTvJiz6JKvDtFf34DX) |
| ForzaTech importer | [forza.quixel.net](https://forza.quixel.net/), plugins that bring ForzaTech data into 3ds Max and Maya |
| Swatchbin Texture Modding Assistant (STMA) | Converts Forza `.swatchbin` textures to `.dds` (by Tado Hmn) |
| ImageHeat | [github.com/bartlomiejduda/ImageHeat](https://github.com/bartlomiejduda/ImageHeat), viewer for raw game textures, for example NFS No Limits `.sba` files |

Models and textures from other games belong to their publishers. Use conversions for personal use only and do not upload ripped assets.

## Tools

| Tool | What it does |
|------|--------------|
| [Blender ksanim/knh exporter](https://www.overtake.gg/downloads/blender-ksanim-knh-exporter.30388/) | Exports animations from Blender as `.ksanim`. Only works on objects with a parent, not on root nodes |
| [PureRef](https://www.pureref.com/) | Reference image viewer: many photos and notes in one window |
| RizomUV Bridge | Blender bridge to RizomUV, makes unwrapping much easier |
| [Vertex Warehouse](https://www.vertex-warehouse.com/) | Online car base models (the site did not respond on 2026-11-19) |
